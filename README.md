
# Maria Albano | Cybersecurity Portfolio

## Project Overview
This website is my personal cybersecurity portfolio,
created for my Introduction to Computer Science course
at American International College.

The website highlights my education, certifications,
career goals, and cybersecurity and programming projects.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Responsive web design

## Website Pages
- Home: Introduction, education, certifications, and professional links.
- Portfolio: Cybersecurity and programming projects.
- Policy: My perspective on artificial intelligence in cybersecurity.

## Career Goals
My goal is to become a cybersecurity analyst,
advance into incident response, and eventually
specialize in digital forensics.

## AI Assistance
I used AI assistance to help organize HTML,
refine CSS styling, review code, and improve
the website's mobile layout. I reviewed and
tested the suggested changes.
